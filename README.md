# 解环工坊（Blender）

解环工坊将原版解环搭建器的网页、素材与解谜逻辑整合进一个 Blender 扩展。关卡建模和动画沿用原有规则，文案、HUD、结尾卡、分镜和音效交给后期处理。

## 关于

本项目由 **ZCode（AI 编程 Agent）全程编写**——基于 GLM 大模型驱动，从需求分析、架构设计、逐模块实现、物理调参到自动化测试全部由 AI 完成，人类负责提需求、验收效果和决策方向。

- AI 模型：GLM（智谱）
- Agent 框架：ZCode CLI
- 人类角色：产品经理 + 测试验收

## 安装

1. 使用 Blender **5.1.0 或以上**。安装前停用独立安装的「解环关卡搭建器」，以及使用同一套操作符的旧「买量工坊 UA Studio」，避免重复注册。旧工程不需要删除。
2. 在 Blender **编辑 → 偏好设置 → 插件 → 从磁盘安装**中选择合并版 `ua_game_kit-0.3.15.zip`；更新已运行的插件后，保存工程并完全退出 Blender，再重新打开。不要解压安装 ZIP，也不再另装搭建器 ZIP。
3. 在 3D 视口按 `N`，打开「解环工坊」。

## 工作流

| 面板 | 内容 |
| --- | --- |
| 工程 | 从插件打开内嵌网页搭建器并发送关卡，或直接导入搭建器 JSON。关卡导入后**默认立起**：正视相机、水平地面、背景板和灯光自动生成；勾选「导入后自动立起」控制该行为，取消则保持俯拍平铺。「一键广告模板」按真实解谜顺序烘焙当前关卡，保留模型、关卡画幅和活动相机，设定整个动作的输出帧范围。没有关卡或活动相机时不会生成替代场景。 |
| 阵列、材质 | 只保留面板，暂无工具。搭建器原有的关卡主题材质照常导入。 |
| 解环动画 | 解开选中环（也可以选卡扣）、烘焙全关卡、清除解环动画。模式、方向、单步时长、移出和淡出仍可选择。「恢复平铺」和「立起关卡」随时切换俯拍与立式。破碎分「碎块」和「沙粒」两种效果，各支持整体或沿 C 口逐段时序。 |
| 物理 | 「一键破碎」作用于选中的网格，自动把当前可见的地面（立式地面或搭建器地面）设为固定碰撞体。没有地面也能破碎，碎片不会自动落地。使用时需要 Cell Fracture，可从「前置插件」面板启用。 |
| 相机 | 保留原有运镜和构图工具。先在 3D 视口调整视角，再点「当前视角设为相机新视角」。 |
| 渲染 | 渲染当前关卡、批量渲染、多画幅、封面和交付包。交付包不生成音效清单或结尾卡。 |

全关卡烘焙和一键模板都会替换本关卡之前的解环关键帧。没有添加模拟手指、飞槽或通用广告演示场景。UE5 和 C4D 不在这版改动范围内。

## 手动定帧破碎

1. 关卡导入后默认已是立式：正视相机、水平地面、竖直背景板和面向环的灯光自动生成，画面下方留出下坠空间。点「恢复平铺」回到俯拍姿态（同时恢复原相机和原布景显隐），再点「立起关卡」随时切回；解环变换关键帧不会被旋转或重写。不需要默认立起时，在「工程」取消「导入后自动立起」。
2. 在破碎区选择「效果」和「时序」：效果「碎块」切成弧形碎块，下落轨迹可逐帧编辑；效果「沙粒」散成物理细沙圆粒，落地自然堆积。时序「整体」同一帧释放；时序「逐段」沿 C 口从一端依次释放（仅 C 形环支持，整环请用整体）。选中目标环，无需先解开它，解环动作进行中也可以破碎。如果原环已淡出，可以用「指定环」选择。该字段留空时使用视口选中的环。
3. 将时间轴停在想开始破碎的帧，点「执行破碎」。沙粒模式在所选帧保留完整原环，从下一帧开始脱落实体碎块；细沙随后在碎块下落中分批释放。碎块模式从所选帧释放。

立式状态下，在「工程」重建背景、地面和灯光时只更新立式布景。背景可用双色渐变、纯色或影棚色；立式「天空光」使用顶部柔光，不覆盖场景的世界设置。原有解环变换关键帧不变。

「散开幅度」控制碎片释放时的初始分离速度，之后按场景重力下落。设为 0 不额外添加分离速度。碎块的下落是可编辑关键帧，不需要刚体烘焙，也不计算落地碰撞；对已有碎块切换姿态会保留释放时间和世界重力方向。逐段碎块可设传播帧数和方向；要应用新的散开幅度，回到原破碎起始帧，重新点「执行破碎」。

「沙粒」先从原环切出实体碎块：碎块脱落后先翻转下坠，随后从自身网格分批撒出细沙，并逐渐缩小。整体模式的碎块同时脱落；逐段模式沿 C 口依次脱落，扫到之前的弧段仍保持完整。细沙使用刚体模拟，落地后可碰撞、堆积，插件会自动烘焙缓存。可以调弧段数（逐段模式，受传播帧数限制，最多 14 段）和沙粒数量。沙粒需要可见地面，建议使用默认立式布景。「叠加沙尘」生成随正在下落的沙粒移动的体积雾，不参与碰撞；请用材质预览或渲染查看雾效，实体模式下只显示线框轮廓。切换姿态会重新模拟沙粒，「清除解环动画」会一并移除碎片、弧段、沙粒和沙尘。为旧场景更新效果时，请指定原环、回到原破碎起始帧，再执行一次破碎，不需要清掉解环动画。

同一环重新破碎会替换原碎片，保留原解环旋转和位移。原环及其扣件在破碎帧切换显隐，目标环原有淡出会被替换。「清除解环动画」会一并清除解环关键帧和手动碎片。

## 从源码构建

使用提供的原始 `ring_level_builder_blender_v1.7.0.zip`（构建脚本校验其 SHA-256）。先组装合并版到一个不存在的新目录，再执行 Blender 官方打包命令：

```bash
python3 -I stage_extension.py /path/to/ring_level_builder_blender_v1.7.0.zip /tmp/ring-workshop-source
blender --background --factory-startup --command extension build --source-dir /tmp/ring-workshop-source --output-dir /path/to/output
```

在隔离的 Blender 用户配置中安装合并版，用 `blender --background --factory-startup --python-exit-code 1 -P tests/smoke_test.py` 运行集成测试。它使用搭建器真实关卡数据，覆盖导入、三种动画操作、模板保留场景与相机、实际出图、打包和重新启用。另可分别运行 `tests/ring_shatter_test.py` 和 `tests/ring_stage_test.py`；后者需要在命令末尾用 `-- /path/to/empty-test-dir` 指定测试文件和样张输出目录。
